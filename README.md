# Komentář k zákonu č. 229/1992 Sb., o komoditních burzách

Otevřený komentář k zákonu o komoditních burzách — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; státní povolení burzy, statut, orgány burzy a burzovní rozhodčí soud, členové burzy, burzovní obchody a pravidla, burzovní dohodci, státní dozor, přestupky a zánik burzy.

Konsolidované znění: dokument e-Sbírky `SB-1992-00229_2024-01-01`.
